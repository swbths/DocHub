# 文枢 · DocHub

**文枢：文档中枢，一键合转。**

把多个 **Word / PDF / 图片**按指定顺序**无损合并成一个 PDF**，把 **PDF 批量转成图片**，把**图片批量转成 PDF**（逐张输出或合并），也可以把 **Word 批量转成 PDF**。

全程本地处理，文件不上传、不外传。

- 当前版本：`4.5.24`（2026-11-13）
- 运行平台：Windows 10 2004（10.0.19041）及以上 / x64
- 技术栈：.NET 10 + WinForms + [PDFsharp](https://github.com/empira/PDFsharp) 6.2.4

---

## 功能特性

### 无损合并

| 类型 | 支持格式 | 处理方式 |
| --- | --- | --- |
| PDF | `.pdf` | 逐页原样复制，不重新排版、不转图片、不压缩画质 |
| Word / WPS | `.doc` `.docx` `.docm` `.dot` `.dotx` `.dotm` `.rtf` `.odt` `.wps` `.wpt` | 由本机 Word、WPS Office 或 LibreOffice 导出 PDF 后合并，保留原始版面；原生 WPS 文件优先交给 WPS Office |
| 图片 | `.jpg` `.jpeg` `.jfif` `.png` `.bmp` `.tif` `.tiff` `.gif` `.webp` `.heic` 等 | 按原始尺寸排成单页 PDF，不缩放、不裁剪；HEIC / AVIF 需系统已装对应解码扩展 |

图片转换按 CPU 核心并行执行；合并过程实时显示进度与状态。

### PDF 转图片

| 项目 | 说明 |
| --- | --- |
| 输入 | `.pdf`，支持一次添加多个文件或整个文件夹（递归收集），可拖拽排序、移除 |
| 输出格式 | PNG / JPEG / BMP / TIFF，默认 JPEG |
| 分辨率 | 默认 300 PPI；可选 72 / 96 / 150 / 300 / 600 PPI，或自定义 36–1200 PPI；同时显示预计像素尺寸 |
| JPEG 质量 | 默认 100%，1–100 可调，仅 JPEG 生效 |
| 透明背景 | 仅 PNG 支持；其他格式固定白底 |
| 页码范围 | 全部页 / 奇数页 / 偶数页 / 自定义范围（如 `1-3,5,8-10`） |
| 输出位置 | 与源文件同目录 / 上次使用的目录 / 自定义目录；默认每个 PDF 单独建子文件夹，并在名称后附加页码模式（如 `报告_偶数页`） |
| 图片命名 | 与合并共用命名方式（首个文件名 / 自定义短语 / 时间戳 / 自定义名称），输出如 `名称_p001.png`，页码自动补零 |
| 实时预览 | 添加 PDF 后自动渲染当前页码模式下第一张导出的页面，改格式 / PPI / 背景立即刷新 |

- 加密 PDF 会先询问打开密码，密码仅用于本次转换，不写盘
- 批量转换中单个文件失败不会中断整批，结束后汇总成功 / 失败数量
- 点击「开始转换」后按钮变为「取消」；取消时保留已导出的图片
- 可在「水印」设置页为 PDF 转图片开启水印：水印只叠加在输出图片上，源 PDF 始终只读
- 全程只读源 PDF：不修改原文件的文字、图像或页面，转换前后源文件保持一致

### 图片转 PDF

| 项目 | 说明 |
| --- | --- |
| 输入 | `.jpg` `.jpeg` `.png` `.bmp` `.tif` `.tiff` `.gif` `.webp` 等，支持多选、拖入文件夹（递归收集）、拖拽排序与移除 |
| 输出 | 默认每张图片单独生成一个 PDF；开启「合并为一个 PDF」后按列表顺序合成一个 PDF |
| 纸张 | 自动 / A4 / A3 / A5 / B5 / Letter |
| 方向 | 自动 / 纵向 / 横向；自动时跟随图片宽高 |
| 页边距 | 无 / 10 mm / 20 mm |
| 适配方式 | 自动纸张按图片像素与 DPI 定页；固定纸张等比缩放居中，不裁切、不拉伸 |
| 输出位置 | 与合并共用：首个图片同目录 / 上次使用目录 / 自定义目录，文件重名自动追加 `-1`、`-2` |
| 文件命名 | 默认使用图片原文件名；可自定义文件名，逐张输出自动追加 `_001`、`_002`；合并时留空则沿用合并命名 |

- 默认逐张输出，单张失败会继续处理其余图片，结束后汇总成功 / 失败数量
- 转换在后台线程执行，可随时取消；逐张输出保留已完成的 PDF，合并输出不会留下半成品
- EXIF 方向自动校正，透明图片按白底合成
- 损坏或无法解码的图片会给出明确提示，不影响其余文件检查

### Word 转 PDF

| 项目 | 说明 |
| --- | --- |
| 输入 | `.doc` `.docx` `.docm` `.dot` `.dotx` `.dotm` `.rtf` `.odt` `.wps` `.wpt`，支持多选、拖入文件夹（递归收集）、拖拽排序与移除 |
| 输出 | 默认每个 Word 单独生成同名 PDF，重名自动追加 `-1`、`-2`；开启「合并成一个文件」后按列表顺序合成一个 PDF |
| 文件命名 | 逐份输出使用 Word 原文件名；合并时可自定义文件名，默认取第一个 Word 的文件名，留空自动回退 |
| 转换引擎 | 自动使用本机 Microsoft Word、WPS Office 或 LibreOffice；`.wps` / `.wpt` 由 WPS Office 或 LibreOffice 转换，三者都未安装时给出明确提示并禁用开始按钮 |
| 输出位置 | 默认第一个 Word 所在目录；可浏览选择并记住上次位置 |
| 水印 | 在「水印」设置页单独开启「Word 转 PDF」后，水印只叠加在输出 PDF 上，源 Word 不会被修改 |

- 加密 Word 会在开始前询问打开密码，密码仅用于本次转换，不写盘
- 转换在后台线程执行，可随时取消；取消或失败时会清理本次产生的不完整 PDF

### 文件列表

- 拖入文件、拖入文件夹（递归收集可识别文件）或「添加文档」
- 列表中直接**拖拽调整顺序**
- **多选**后右键：上移 / 下移 / **置顶** / **置底** / 删除
- 一键清空、实时文件计数、重复文件自动跳过

### 带密码的文件

- 加密 PDF：合并前弹出密码框，密码错误可立即重输，校验通过才继续
- 加密 Word（`.docx` `.docm` `.dotx` `.dotm`）：按文件结构识别后同样询问密码
- 密码仅用于本次合并，不写盘、不记入设置

### 水印

- 作用范围：可在设置中分别开启「文档合并」「PDF 转图片」「图片转 PDF」「Word 转 PDF」，四个开关默认关闭；样式为四项共用
- 文字：4 种预置（正本 / 副本 / 机密 / 绝密）+ 任意自定义文字
- 字体：微软雅黑、等线、宋体、黑体、楷体、仿宋及常见西文字体，只列出系统已安装的选项；预览与输出随选择即时更新
- 样式：斜纹平铺，或固定在左上 / 右上 / 居中 / 左下 / 右下；颜色灰 / 红 / 蓝
- 参数：**透明度 0–100%**、**大小 10–400%**、**方向 -180°~180°**、**水平/垂直位置 ±100%**，滑块可拖动，点击数值也可直接键入
- 预览即所得：拖动移动、滚轮缩放、右键拖动旋转、双击复位；水印按页面比例生成透明图层叠加，不遮挡可读性、不产生压缩噪点
- 自动防裁切：水印过大或被拖到页面边缘时按旋转后外框等比缩放并限制在页面内，合并后不会出现「只显示一半」
- PDF 转图片的水印只写入输出图片，源 PDF 不会被修改

### 输出与命名

- 命名方式：首个文件名 / 自定义短语 / 时间戳 / 自定义名称
- 保存位置：与首个文件同目录 / 上次使用的目录 / 自定义目录
- 完成后一键「查看结果」，内置 PDF 阅读器支持翻页与缩放

### 体验

- 左侧卡片式导航：文档合并 / PDF 转图片 / 图片转 PDF / Word 转 PDF；水印、完成提醒、皮肤、设置与关于固定在左下角
- 四个工作区的文件列表均支持拖拽排序、空白处鼠标框选与 Shift 连选；普通点击（包括 Ctrl+点击）只保留当前文件，上一行的选中立即消失。选中后可批量移除，点「取消框选」或按 Esc 可还原框选前的选择
- 5 套皮肤：经典蓝（默认）、夜间黑、云白、拟物风、新拟态（跟随皮肤自动切换明暗配色，侧栏与正文对比度均按 WCAG 校验）
- 6 种界面语言：简体中文、繁體中文、English、日本語、한국어、Русский
- 合并页右侧内置「每日一言」：毛玻璃圆角卡片，六种语言共 396 条电影台词与名人名言（每种语言 66 条）均注明出处，随界面语言自动更换，启动与运行中均随机播放，默认每 30 秒自动换一句、间隔可在外观设置中自定义（5~86400 秒），点击卡片可立即换一句；可在外观设置中关闭
- 左下角扁平入口（水印、完成提醒、皮肤、设置、关于）悬停有提示、点击直达对应设置页
- `Ctrl+1` / `Ctrl+2` / `Ctrl+3` / `Ctrl+4` 切换页面，`Ctrl+O` 添加文件
- 完成提醒：系统通知 / 5 种提示音（提示音默认关闭，关闭时音效选项置灰） / 完成后自动打开
- 应用内提示框（确认、警告、错误、询问与密码输入）全部跟随当前皮肤，深色皮肤下不再出现系统白色弹窗
- 支持托盘常驻，所有设置即时生效、自动保存到 `%APPDATA%\DocHub\settings.json`

## 安装

### 安装版（推荐）

运行 `文枢_安装程序_v4.5.24.exe`：

- 默认安装到 `%LOCALAPPDATA%\Programs\DocHub`（当前用户目录），**不需要管理员权限**，也不写 `C:\Program Files`，不会触发 UAC，可自定义目录：输入或浏览选择的任意位置都会原样生效（若选到 `C:\Program Files` 下，界面会提示普通用户通常没有写入权限，建议改到用户目录或其它磁盘）
- 创建开始菜单「文枢」及桌面快捷方式，开始菜单内附「卸载 文枢」
- 在「设置 → 应用 → 已安装的应用」中可见，可直接卸载
- 覆盖安装会先关闭正在运行的程序、静默卸载旧版本，无需手动清理
- 若曾装过旧版 **机器级** 安装（`C:\Program Files (x86)\DocHub`），请先到「设置 → 应用 → 已安装的应用」里卸载旧版本再安装新版：本安装器按当前用户安装、没有管理员权限，无法自动清理机器级旧目录与其 HKLM 卸载项（安装时会提示，不会擅自删除）
- 卸载后自动清除程序目录、注册表项与快捷方式

静默模式（供批量部署与自动化测试；安装器为本项目自研，不依赖 NSIS）：

```bat
:: 完整静默安装（当前用户，默认目录 %LOCALAPPDATA%\Programs\DocHub）
文枢_安装程序_v4.5.24.exe --silent

:: 指定安装目录（位于 Program Files 下时同样会自动改回当前用户目录）
文枢_安装程序_v4.5.24.exe --silent --dir D:\Apps\DocHub

:: 仅解压载荷：不写注册表、不建快捷方式，可用于核对安装内容
文枢_安装程序_v4.5.24.exe --extract D:\temp\dochub_payload

:: 静默卸载
"%LOCALAPPDATA%\Programs\DocHub\app\DocHub.exe" --uninstall --yes
```

退出码：`0` 成功、`1` 失败、`2` 参数错误、`3` 部分文件未能写入（安装器的失败清单会一次性列出，不会逐文件弹框）。

### 绿色版

解压 `文枢_绿色版_v4.5.24.zip` 后运行根目录的 `DocHub.exe` 即可，不写注册表、不创建快捷方式。程序为自包含发布，**无需安装 .NET 运行时**。

## 使用说明

1. 左侧选择「文档合并」
2. 拖入或添加需要合并的 Word / WPS / PDF / 图片
3. 在列表里调整顺序（可拖拽，也可右键置顶/置底）
4. 若文件带密码，按提示输入打开密码
5. 如需水印，在设置「水印」页勾选文档合并并调整字体、透明度、大小、方向、位置
6. 在设置中选择命名方式与保存位置
7. 点击「开始合并」，完成后可「查看结果」

PDF 转图片：

1. 左侧选择「PDF 转图片」
2. 添加一个或多个 PDF（可拖入文件夹，递归收集）
3. 选择格式、PPI（可自定义）和页码模式（全部 / 奇数页 / 偶数页 / 自定义范围）；默认 JPEG / 300 PPI / 质量 100%，PNG 可开透明背景
4. 选择输出位置，点击「开始转换」；批量失败会汇总提示，取消会保留已导出的图片
5. 如需在输出图片上加印，在设置「水印」页勾选 PDF 转图片；源 PDF 不会被修改

图片转 PDF：

1. 左侧选择「图片转 PDF」
2. 添加或拖入图片（可拖入文件夹，递归收集），按需拖拽调整顺序
3. 选择纸张（自动 / A4 / A3 / A5 / B5 / Letter）、方向与页边距
4. 默认每张图片单独输出；需要合成一份时勾选「合并为一个 PDF」
5. 文件名为空时逐张使用图片原名，或填写自定义名称（逐张输出自动追加序号）
6. 确认输出位置后点击「开始转换」，完成后可一键打开 PDF 或文件夹

> Word 文件需要本机已安装 **Microsoft Word** 或 **LibreOffice**；只合并 PDF / 图片、只做 PDF 转图片或图片转 PDF 时无此依赖。
> 旧版 `.doc` 若设置了打开密码，程序无法自动识别，请先用 Word 另存为 `.docx`。

## 从源码构建

环境要求：

- .NET SDK 10（`dotnet --version` 需 ≥ 10.0）
- .NET Framework 4.x（用于编译精简启动器 `csc.exe`）
- 安装包不需要任何第三方打包工具：安装器是本仓库内的 .NET 程序（`installer\Setup.csproj`），由同一个脚本编译

```powershell
# 一键构建：自包含发布 + 启动器 + 绿色版 zip + 自研 .NET 安装器
powershell -ExecutionPolicy Bypass -File tools\package.ps1
```

产物输出到 `dist\`：

- `文枢_安装程序_v4.5.24.exe`
- `文枢_绿色版_v4.5.24.zip`

只编译主程序：

```powershell
dotnet build DocHub.csproj -c Release
```

> 脚本会把发布结果放到 `build\layout\app\`，主程序 `DocHub.exe` 收进 `app\`，根目录只保留一个同名的 `DocHub.exe` 启动器（英文文件名，避免中文路径名触发写入失败）；随后把整个 layout 压成 `installer\payload.zip` 内嵌进安装器，并清除 layout 中所有文件的网络标记；`build\` 与 `payload.zip` 在打包结束后自动清理。

## 常见问题

**提示缺少 Word 转换组件？**
安装 Microsoft Word 或 LibreOffice 后重试，或选择跳过 Word 文件继续合并其余 PDF / 图片。

**合并速度慢？**
Word 转 PDF 依赖 Office 启动，首个文件较慢；纯 PDF / 图片合并且页数较多时主要耗时在磁盘写入。

**双击安装包提示「Windows 安全中心：打开这些文件可能会对你的计算机有害 / 你的 Internet 安全设置阻止打开一个或多个文件」？**
这是 Windows 对「从网上下载的文件」的区域检查（文件带「来自网络」标记，Zone.Identifier），不是病毒提示，与程序本身无关。任选一种方式即可继续：
1. 右键安装包 →「属性」→ 勾选底部的「解除锁定」→「确定」，再双击安装（一次性操作，最干净）；
2. 直接点提示框里的「确定」，也能继续安装；安装程序启动后会清掉自身的该标记，之后再运行不会再提示；
3. 从命令行下载则不会写入该标记，例如在 PowerShell 里执行 `Invoke-WebRequest '<安装包下载链接>' -OutFile "$env:TEMP\dochub_setup.exe"`，然后运行 `$env:TEMP\dochub_setup.exe`。

> 说明：这一层提示来自操作系统对**带标记的可执行文件本身**的策略，只要文件是从网上下载且未做代码签名，首次双击仍可能被提示一次；安装器能做到的是：安装产物（`%LOCALAPPDATA%\Programs\DocHub` 下的全部文件）与安装后的每次启动都不再出现任何提示。若希望完全避开，可直接使用绿色版压缩包。
> 绿色版同理：用 7-Zip / Bandizip 等工具解压（Windows 自带「全部解压缩」会把标记带进解压出的文件）；启动器 `DocHub.exe` 会在拉起主程序前清掉安装目录与 `app\` 下所有文件的标记，因此首次运行最多只有启动器自身被提示。

**安装完成后运行时还会弹提示吗？**
不会。安装器在解压完成后会递归清除安装目录下**所有文件**（不限扩展名，含 `app\lib`）的网络标记，程序启动时还会再兜底清一次；绿色版由启动器在拉起主程序前完成同样的清理。

**安装时提示「Microsoft Defender SmartScreen 阻止了无法识别的应用启动」？**
这是 Windows 对未签名程序的通用提示，并非病毒告警。点「更多信息」→「仍要运行」即可继续安装。本程序为开源项目、未购买代码签名证书，因此保留该提示；安装包内已写入完整的版本信息，可在「属性 → 详细信息」核对版本。
若从网上下载后提示被阻止，也可先解除锁定：右键安装包 →「属性」→ 勾选「解除锁定」→「确定」。

**合并时提示「合并失败：Access to the path … is denied」？**
这是创建合并用的临时目录被拒绝，通常是腾讯电脑管家、360、火绒等安全软件在拦截未知程序写入。把 `DocHub.exe` 加入安全软件的信任区（或临时关闭实时防护）后重试即可。纯 PDF 合并不需要临时目录，即使被拦截也能正常完成；含 Word / 图片的合并才需要。

**安装包双击后没有任何反应？**
请把安装包复制到桌面或其他普通目录后再运行（个别受管控的目录会阻止安装器启动）。

**安装时提示「无法打开要写入的文件」（中止 / 重试 / 忽略）或者卡在某个文件上？**
4.1.0 起的安装器是自研的 .NET 程序，**不会**再出现「中止 / 重试 / 忽略」这类逐文件对话框：单个文件写入失败会自动重试 3 次，仍失败则跳过并累计，安装结束后一次性列出最多 10 条失败项，已写入的文件保留。
看到失败清单时，按提示处理即可：
1. 完全退出正在运行的程序（含托盘图标）；安装器也会自动结束 `DocHub.exe`；
2. 暂时关闭安全软件（360、腾讯电脑管家、火绒等）的「文件实时防护」，重新运行一次安装程序，装完再打开；
3. 或直接使用绿色版压缩包，解压即用、不写系统目录、不写注册表。

**安装时提示「安装未能完成：Access to the path …\Programs\DocHub is denied」？**
首选目录被安全软件或权限策略挡住时，安装器会**自动逐个尝试**其它位置：`%LOCALAPPDATA%\DocHub`、`%LOCALAPPDATA%\Programs\DocHub`、`%USERPROFILE%\DocHub`、`%APPDATA%\DocHub`、公用目录 `C:\Users\Public\DocHub`、安装包所在目录下的 `DocHub`，最后还会尝试其它固定磁盘的 `X:\DocHub`。每个位置都会先真实写入一个探测文件确认可写；成功后结果页会写明实际安装位置（类似「原目录无法写入，已改为安装到：…」），快捷方式和卸载登记也指向该位置。
如果所有位置都被拒绝，安装器会在安装包旁（不可写时写到 `%TEMP%`）生成 `setup-error.log`，里面列出每个目录的具体错误；把安装目录改到其它盘后重试，或暂时关闭安全软件的「文件实时防护」，也可以直接用绿色版压缩包。

**安装到 `C:\Program Files` 可以吗？**
不推荐，也不需要。安装器默认装到当前用户目录 `%LOCALAPPDATA%\Programs\DocHub`，**不写 Program Files、不触发 UAC**；即使手动把路径填成 `C:\Program Files\...`，安装器也会自动改回当前用户目录并在界面上说明一行。

**卸载后残留？**
正常卸载会清理程序目录、注册表项与快捷方式；若手动删除过文件，可在「已安装的应用」中再次卸载以清理登记项。
